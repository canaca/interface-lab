Lab UI

Concepts were built fast with AI and didn't match. This page is the system pulled out of them: the same tokens, the same components, and the accessibility gaps closed.

Demo only. The shops, people, and amounts on this page are fictional. Nothing is sent, charged, or published. A Figma mirror of these tokens is planned. It is not built.

Role
Concept direction
Tools
AI-assisted build (Claude, Cursor)

Tokens

Checked against WCAG 2.2 AA for text under 18px (4.5:1) and for large text or UI marks (3:1). The dim color is the one Linden already used. It replaces #7F6B5B, which was 3.80:1 on the page background and failed for small text.

Type

12px · labels and meta. Hanken Grotesk.

14px · secondary text inside a piece.

16px · body. This page uses 16px so it stays readable on a phone.

20px · section titles inside a demo.

28px · page sections.

40px · the piece title.

JetBrains Mono · times, ids, and the role line.

Space, radius, motion

Space steps are 4, 8, 12, 16, 24, 32, and 48. Radius is 8 for fields, 12 for controls, 18 for panels, and a pill for chips. Motion is 120ms, 200ms, and 360ms. When the system asks for less motion, those durations are 0 and the block below does not travel.

Components

Fourteen parts taken from the pieces that are already on the hub. Each control in a demo does something. State buttons switch the real demo, and choosing the state you are already on says so.

Don't use

    One system after the fast builds

    Concepts were built fast with AI and didn't match. I extracted one system, fixed the accessibility gaps, and aligned the pieces on it.

    Cesar Navarro · cnavarro.business@gmail.com

    Role
    Concept direction
    Tools
    AI-assisted build (Claude, Cursor)
    Problem
    Each piece had grown its own chips, toasts, errors, and type color. Small text in the dim brown failed contrast. Two pieces did not honor reduced motion. Focus rings did not match.
    Decisions
    Tokens live on this page with the contrast ratio next to each color. Components are the ones the pieces already use, including empty, loading, error, and disabled. Confidence is words, not a percent. A Figma mirror is planned and is not claimed as done. No 3D.
    Outcome
    A working system page, and the live pieces moved onto the passing dim color, a 2px focus ring, and full reduced-motion styles. Not a shipped design-system product. Not tested with a team.
