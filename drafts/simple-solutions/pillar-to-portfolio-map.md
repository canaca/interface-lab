# Pillar → portfolio map

**Status:** Draft. Not a posting calendar. Social copy still follows `content-pillars.md`: no prices, no dollar amounts, no invented results, and the Zoom CTA only.

**How to use a piece in a post:** one idea, a short screen recording or a single labeled frame, fictional data called out as sample data, and a link to the live demo only if that demo is already public. Planned pieces are not public. Do not post them as if they are live.

**Role line if a post mentions who made the piece:** concept direction, AI-built and directed. Do not say Cesar wrote the code or the Blender scripts. Do not call case-study writing a skill.

**CTA when a post asks for a conversation:** Book a free Zoom call: message us or email cnavarro.business@gmail.com for the link.
