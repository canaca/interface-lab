AgentProof

Authorization demo

Beta format · fictional · concept service

A person confirms one fictional purchase. This page signs that confirmation in the browser. A merchant check then accepts it, or undoes it, against a pinned public key.

Northwind Goods, Harbor Shopping Agent, and Alex Rivera are fictional. No payment is collected. No order is sent to a store. No dispute is filed. The AgentProof service is still a concept. Version 0.1.0 of this file says so inside the signature.
