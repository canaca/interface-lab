AgentProof

Concept / early access, not a live service

AgentProof is an idea for a service that would let an AI agent show a store that a person approved a purchase the agent made for them.

If that charge were later disputed, the store would get a packet describing what the person approved. The packet is meant for a Shopify or Stripe dispute. This page does not file disputes, and it does not say what a bank or card network would decide.

How it would work

  1. An agent is about to buy something for a person.
  2. The person confirms that purchase, in words they can read.
  3. The agent would send AgentProof that confirmation, the amount, and whether the store uses Shopify or Stripe.
  4. AgentProof would keep a record and, if the charge is disputed, hand the store a short evidence packet.

Those steps are the idea. None of them run here.

What this page is

A static description, so a person or an agent can find the idea and read it. GitHub Pages only serves files. It does not accept the proof request, store a card, or open a dispute.

There are no customers and no results to report, because the service is not running. The only next step is the waitlist.
