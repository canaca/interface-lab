ConceptGrid operations · live 3D

Helping grid operators act on an equipment alert

From first warning to a crew on site, on a 3D model of the equipment itself.

Role
Concept direction
Tools
AI-assisted build (Claude, Cursor)
Read the case study
Problem
Grid operators get alarms with numbers but no context, so deciding whether to send a crew means jumping between screens and phone calls.
User
A control-room operator on shift, responsible for nine substations.
Decisions
The equipment is the interface. One panel holds the whole path. Evidence comes before advice. Every action confirms before it sends. Every state is designed.
Outcome
A working prototype of the full alert workflow, with a live 3D scene built with AI-assisted tooling (Claude, Cursor) running in the browser and a 15-second film mode. Not tested with real operators or live data.
Label
Concept. Fictional data, people and substation.
